# Forecasting

Time-series forecasting (revenue, demand, churn risk) using statsmodels
(ETS/ARIMA) as a baseline, with room to add a learned model once there's
enough historical data to justify one. Called by `services/analytics-engine`.

**Status:** Not yet implemented. Planned for Phase 3 (basic forecasting) and
extended in later phases as Predictive Analytics use cases grow.
