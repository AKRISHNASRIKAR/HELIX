# Root Cause Analysis

Combines correlation, segmentation, and anomaly signals across agents' findings
into a candidate root cause with a confidence score — the computational
backbone behind `Investigation.rootCauseFinding`. This is Diagnostic
Analytics, and its output feeds the Coordinator, not the other way around.

**Status:** Not yet implemented. Planned for Phase 10 (Explainability +
Replay), once multiple agents (Phase 7) are producing findings to correlate.
