# Finance Agent

Owns revenue, refunds, payments, and other financial metrics as investigation
evidence.

Will implement `BaseAgent` from `services/agent-runtime/app/agents/base.py`.

**Status:** Not yet implemented. Planned for Phase 7 as the first domain
agent added alongside the Coordinator and Analytics Agent (the brief's
"1. Coordinator 2. Analytics 3. one domain agent" sequence — Finance was
chosen as that third agent since revenue/refunds are the most concrete,
easily-verifiable metrics to investigate first).
